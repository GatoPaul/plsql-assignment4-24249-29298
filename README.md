## Application Description
This application is a Student Registration and Grading system built using Oracle PL/SQL. It manages students, courses, and their enrollments. It demonstrates the use of Records, Collections, Implicit/Explicit Cursors, Bulk Processing (BULK COLLECT and FORALL), Stored Procedures, Functions, and Exception Handling.

## How to Run
1. Run `00_schema/01_create_tables.sql`.
2. Run `00_schema/02_insert_sample_data.sql`.
3. Compile the stored procedures in `01_procedures/`.
4. Compile the stored functions in `02_functions/`.
5. Run the test files in `03_tests/` to see successful execution and error handling.
